🧾 Описание:
------------
Это простой RESTful API-сервер для управления задачами (to-do list), реализованный на FastAPI. 
Задачи хранятся в JSON-файле (`db.json`). Каждая задача содержит:
- `id` (уникальный идентификатор)
- `name` (название)
- `description` (описание)
- `data_create` (дата создания)


📁 Структура проекта:
---------------------
- `main.py`         — точка входа, определяет маршруты FastAPI
- `crud.py`         — содержит логику операций: чтение, создание, обновление, удаление задач
- `model.py`        — описывает модель данных `Task`
- `db.json`         — база данных (в виде JSON-файла)
- `README.txt`      — документация


🚀 Запуск проекта:
------------------
1. Установите зависимости: pip install fastapi uvicorn
2. Запустите сервер: uvicorn main:app --reload
3. Откройте в браузере:
    - Документация Swagger: http://127.0.0.1:8000/docs
    - Главная страница API: http://127.0.0.1:8000/

📌 Доступные маршруты:
----------------------

🔹 GET `/`  
    — Главная страница.

🔹 GET `/tasks`  
    — Получить все задачи.

🔹 GET `/task_by_id/{task_id}`  
    — Найти задачу по `id`.

🔹 GET `/task_by_name/{task_name}`  
    — Найти задачи по имени.

🔹 GET `/task_by_name/{task_name}/{sort_asc}`  
    — Найти и отсортировать задачи по имени по дате (`sort_asc=True/False`).


🔹 POST `/tasks`  
    — Создать новую задачу.  
    Пример тела запроса:
    ```json
    {   
        "name": "task22",
        "description": "Practice guitar",
        "data_create": "string"  // игнорируется, устанавливается автоматически
    }


🔹 PUT /tasks/{task_id}
    — Обновить задачу по id. Если в полях будет string, старое значение сохранится.

🔹 DELETE /delete_task_by_id/{task_id}
    — Удалить задачу по id.

🔹 DELETE /delete_tasks_by_name/{task_name}
    — Удаляет все задачи, у которых имя совпадает с {task_name}.




📝 Примечания:
    Все изменения сохраняются в db.json.
    ID задач генерируется случайно из букв и цифр.
    Сортировка реализована вручную (алгоритм выбора).
    Дата создаётся автоматически при добавлении задачи.
